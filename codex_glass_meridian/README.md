# Glass Meridian

Original music generated by Codex / OpenAI, 26 September 2026. This folder is the complete independent working area for this composition.

32-bar straightahead post-bop tune, F major centre, 4/4, medium-up swing at quarter = 164. The form is A A2 B C, eight bars each. A four-note cell (concert A-C-G-B) connects the head and the two-chorus trumpet/guitar solo. Bright major triad pairs, non-diatonic major-9/sharp-11 areas, shifted pentatonic fragments, a 3+3+2 expansion, counterlines, and short bebop gestures develop that cell.

## Playing

Head in, two written duo choruses, head out. The head's last bar, F6/9, is also the last bar of every solo pass. End there after the out-head. There is no added turnaround, intro, or coda.

The guitar is the second melodic voice; leave the written gaps rather than filling them with comping. A rhythm section can keep the pulse and harmonic frame. For an unaccompanied trumpet/guitar performance, accept the more open harmonic texture. Notated eighths should swing lightly, not heavily. The native MuseScore files use a 60:40 eighth-note playback setting, as a sketch rather than a substitute for phrasing.

The head reaches concert A5. The solo has three concert C6 peaks (written D6), at bars 20, 52 and 55. A lower-register option is to move the complete trumpet phrases at 20-21 and 52-55 down one octave. The files retain the original line.

## iReal

Open `output/ireal/import_glass_meridian.html` in a browser and follow its import link; or open that HTML file through iReal Pro's File > Open command. Set playback to jazz swing, tempo 164, two choruses for the duo. Chords are in concert pitch. Two symbols in a measure change at beat 3.

The HTML was opened in the installed iReal Pro and its complete import preview inspected: all 32 bars appeared in eight four-bar systems with the correct chord qualities. The initial notation pass stopped at preview. For the subsequent audio recording, the chart was imported into iReal Pro and rendered at 164 BPM for four choruses. The legacy `.irealbook` text file contains the same URL; use the HTML as the main importer.

The encoder follows the [official iReal custom chord chart protocol](https://www.irealpro.com/ireal-pro-custom-chord-chart-protocol/), with four cells per measure, the supported `^9#11`, `13#11`, `7alt` and `69` qualities, and no compressed repeat form. iReal uses `A` plus an `A2` text cue for the second eight-bar section.

## Verification and rebuilding

`qa/validation.json` records bar-duration, harmony-offset, transposition, native sounding-pitch, iReal cell-count and PDF page-count checks. The final PDFs were rendered and visually checked. No human instrumental performance or rehearsal has been used to validate the composition.

Source generation uses Python's standard library. `source/compose.py` is the editable musical source: each pitch is concert pitch and durations are in eighth-note units. Regenerate with:

```bash
python3 source/compose.py
python3 source/export.py
python3 source/package.py
```

`source/export.py` requires the installed MuseScore 3 command-line executable at the path used on this Mac (edit its `MUSESCORE` variable on another computer). `source/package.py` requires ReportLab and pypdf. Run those three steps in order: packaging adds footers to fresh MuseScore PDFs. The source directory contains an isolated engraving style, and MuseScore uses a configuration directory inside this folder rather than changing normal preferences.

The ZIP contains the PDFs, portable MusicXML, native `.mscz` scores, iReal files, source scripts, this README and the validation report. Temporary rendered pages and MuseScore's local configuration remain outside the ZIP.
